# Backlog

Where the code does not yet match `docs/PATTERNS.md` or `docs/UI.md`. These are
findings, not licences: new work follows those two files. A row leaves when it is
fixed, and a backlog that keeps solved rows stops being read.

Every row names what it is waiting for. A row with no trigger is a row nobody can
ever retire, and four of the eight the Patterns table once held were closed in
one pass precisely because each said what would close it.

The rows below are `docs/PATTERNS.md` §11's and `docs/UI.md` §12's, moved here
unchanged. Both of those headings stay where they were, reduced to a pointer at
this file, because dozens of comments in `src/` and `harness/` cite them as
addresses and none of those citations may change.

Add a row when a review finds a gap it is not fixing in the same pass.
